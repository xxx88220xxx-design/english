# 🇬🇧 موقع تعلم الإنجليزية A0 → A2

موقع متكامل لتعلم اللغة الإنجليزية من الصفر (A0) حتى المستوى A2.
كل شيء يعمل **بدون إنترنت**، والبيانات محفوظة على جهازك فقط.

## ✨ الميزات الخاصة

### 🔊 نطق صوتي عالي الجودة
اضغط 🔊 في أي مكان لسماع الكلمة أو الجملة. النظام يجرّب **٣ مصادر بالترتيب**:

| # | المصدر | النطق | يحتاج إنترنت |
|---|--------|-------|--------------|
| 1 | **تسجيل بشري** (Free Dictionary API) | 🎙️ مسجّل من Cambridge/Oxford — **الأوضح** | نعم |
| 2 | **Google Translate TTS** | جمل مُقسَّمة إلى مقاطع قصيرة | نعم |
| 3 | **Web Speech API** | صوت الجهاز | لا |

**كيف نُحسّن الوضوح:**
- ✂️ **تقسيم النص** إلى جمل قصيرة (≤100 حرف) → نطق طبيعي بلا تسارع
- 🐢 **إبطاء حقيقي** عبر `playbackRate` مع `preservesPitch` → أبطأ **دون** تغيّر النغمة
- 🗣️ **تسجيل بشري** لكلمات المفردات → أوضح من أي محرك آلي
- 💾 **كاش** → الكلمة لا تُحمَّل مرتين
- 🚫 **منع التكرار** خلال 0.9 ثانية

**الإعدادات** (صفحة 🔊 ضبط الصوت):
- المصدر: تلقائي / إنترنت / داخلي / إيقاف
- اللهجة: 🇬🇧 British · 🇺🇸 American · 🇦🇺 Australian
- السرعة: شريط `0.50×` – `1.20×` (الوضع البطيء `0.55×`)

**أزرار البطاقة:** 🔊 الكلمة · 🐢 الكلمة ببطء · 💬 الجملة · 🐢 الجملة ببطء

**إذا الصوت غير واضح:**
1. اختر **«إنترنت»** و**اللهجة** المطابقة
2. اضبط السرعة على **0.6 – 0.8**
3. ارفع صوت الجهاز
4. لا تفتح الملف بـ `file://` — استخدم `http://`
5. استخدم متصفح **Chrome**


### 🤖 ذكاء اصطناعي مدمج
- **محادثة حرة**: يرد عليك بالإنجليزية والعربية، ويسألك أسئلة ذهاب وإياب.
- **تصحيح فوري**: اكتب خطأً فيظهر التصحيح والسبب تحت رسالتك مباشرة.
  يكتشف أخطاء مثل:
  - `I am agree` → `I agree`
  - `he don't like` → `he doesn't like`
  - `I have 20 years` → `I am 20 years old`
  - `more better` → `much better`
  - `informations` → `information`
  - `didn't went` → `didn't go`
  - وأكثر من ٥٠ خطأ شائع آخر
- **تمثيل أدوار**: يكتب ما تتوقعه الإجابة، ويعطيك تلميحاً إذا تعثّرت.

### 🃏 تكرار متباعد
البطاقات تُصنّف تلقائياً: **مستحقة / جديدة / ضعيفة**.
الكلمة التي لا تعرفها تعود لك أكثر، والمعرفة تنتقل إلى "أعرفها".

## 📊 حساب السويتة والتقدّم

| المكان | ماذا يُحفظ |
|---|---|
| **اختبار الدرس** (تبويب «اختبر») | `uquiz[الدرس] = { last, best, taken }` + نجوم ١–٣ |
| **تقدّم الدرس** | `units[الدرس]` = عدد الكلمات التي أجبت عنها صحيحاً |
| **كلمات المراجعة** | الكلمات الصحيحة تدخل البطاقات · الخاطئة تدخل «الضعيفة» |
| **الإحصائيات العامة** | `quiz.last` · `quiz.best` · `quiz.taken` |
| **صفحة الإحصائيات** | متوسط نتائج الدروس + جدول 🏅 لكل درس |

- النتيجة تظهر فوراً في **رأس الدرس** (الصندوق الأزرق) وعلى **بطاقة الدرس** (`🏅 80%` + `★★☆`).
- **أفضل نتيجة** لا تنقص بإعادة المحاولة.
- النجوم: `80%+` → ⭐⭐⭐ · `50%+` → ⭐⭐ · `30%+` → ⭐


## 🧹 تشغيل بدون كاش (مهم)

```bash
python3 serve.py 8899
```

`serve.py` يرسل `Cache-Control: no-store` لكل ملف — يمنع كروم من عرض نسخة قديمة
من CSS/JS بينما الـ HTML جديد (وهذا سبب «الصفحة طلعت زبالة»).

في `index.html` كل ملفات CSS/JS فيها `?v=<بصمة>` تلقائياً.

**لتحديث البصمة بعد أي تعديل:**
```bash
cd /root/workspace/english
python3 - <<'EOF'
import io,hashlib
V=hashlib.md5(open('css/style.css','rb').read()+open('js/app.js','rb').read()).hexdigest()[:8]
s=io.open('index.html',encoding='utf-8').read()
import re
s=re.sub(r'\?v=[0-9a-f]{8}', '?v='+V, s)
io.open('index.html','w',encoding='utf-8').write(s)
print('bump to', V)
EOF
```


## 🔥 الستريك اليومي والأسبوعي

يظهر في أعلى القائمة الجانبية (ضُغّط لعرض 212px):

| العدّاد | المعنى |
|---|---|
| 🔥 **ستريك يومي** | عدد الأيام المتتالية بدون انقطاع |
| 📅 **ستريك أسبوعي** | عدد الأيام النشطة داخل الأسبوع الحالي (السبت → الجمعة) من 7 |
| الشريطStrip | 7 مربعات: أخضر = نشاط، بإطار = اليوم، رمادي = قادم |
| التلميح | «متبقي 3 أيام» أو «أكملت الأسبوع كامل» |

**متى يتحسب نشاط؟** فقط عند التعلم الحقيقي:
فتح درس · إنهاء اختبار/سويتة · تصحيح بطاقة · كتابة رسالة في المحادثة.
التنقل بين الصفحات أو فتح التطبيق فقط **لا** يحسب نشاطاً.

يُحفظ في `S.daily = { "2026-09-29": 3, ... }` — يحتفظ بسنوات.
التاريخ يُحسب **بالتوقيت المحلي** (لا UTC) حتى لا ينزلق اليوم حول منتصف الليل.

القائمة: **نطق الحروف** — ثلاث تبويبات:

| التبويب | المحتوى |
|---|---|
| نطقان | الحروف التي لها نطقان (21) — C G S X Y R L N W V Z T CH SH TH P U A O E I |
| كل الحروف | أيضف الحروف البقية صريحة (23) — مع J و K الذي نطقهما واحد |

كل نطق يعرض: الرمز الولاتي `/k/` + **القاعدة** بالعربية + 4-5 أمثلة وأزرار 🔊 لنطقها.

البيانات: `LETTER_SOUNDS` (23 حرف، 44 نطق) و`LETTER_RULES` (5 قواعد) في `js/app.js`.
